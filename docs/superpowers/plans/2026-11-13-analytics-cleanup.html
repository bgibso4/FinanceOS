Analytics cleanup: implementation plan

For agentic workers: REQUIRED SUB-SKILL: use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task by task. Load the principal-engineer skill before writing code.

GoalMake Tailwind opacity tints render, restyle the Analytics chips, make the filter panel collapsible and A–Z, and give Settings → Tags a Total column linking into Analytics.
ArchitectureTheme colours become opacity-capable Tailwind tokens (color-mix + <alpha-value>). There's one shared name-sort helper. A collapsible Section in the panel. Tag totals come from a new spendingByTag next to spendingByDay, using the same per-row spend function.
Stack · SpecNext.js 14, React 19, Tailwind 3.4, Prisma/SQLite, Vitest + Testing Library. Spec: docs/superpowers/specs/2026-11-13-analytics-cleanup-design.html. Mocks: ~/Documents/FinanceOS-design-archive/design-mocks/analytics-chips-filters.html, part 3 of tag-cost-analytics.html.

Global constraints

  • No source file may contain [var(--…)]/N (an arbitrary-var colour with an opacity modifier) after Task 1.
  • Tokens with opacity support: accent, green, red, bg-base, bg-surface, bg-card, bg-elevated, text-primary, text-secondary, text-muted, tag-blue, tag-green, tag-red, tag-yellow, tag-purple, tag-pink, tag-indigo, tag-orange, tag-teal. Format: 'color-mix(in srgb, var(--X) calc(<alpha-value> * 100%), transparent)'.
  • No new colours. --yellow doesn't exist; its one usage (InstitutionCard) becomes accent.
  • Panel spacing: 12px header→contents, 10px under the search box, 16px vertical padding per section.
  • Collapsible sections: Categories, Accounts, and Tags when there are more than 8 tags. All start closed each time the panel opens.
  • Collapsed header summary: picks via capped() in accent; otherwise muted Any · <count>.
  • A tag's Total equals Analytics' all-time Spent for that tag (transfers excluded, net of returns, base currency).
  • "See cost →" href: /analytics? + toSearchParams of { period: custom firstDate..lastDate, vs: 'none', tags: [name] }. No link when the tag has no counted spend.
  • Prettier, ESLint, npm run check must pass. Commit after each task.

Review focus

Inputs the spec implies but doesn't spell out. Each has a test in the task named.

  1. Emoji with joiners and variation selectors (🏌️‍♂️Other Golf, ❗️Stuff I forgot…) sort by their first letter. Test in Task 3.
  2. Searching while groups are folded: a child that matches shows even if its group is folded; a group whose name matches shows all its children. Test in Task 4.
  3. Tag names with spaces, &, / or quotes produce a link that Analytics parses back to the same tag. Test in Task 5 (tagCostHref round-trips through parseAnalyticsQuery).
  4. A tag whose rows are all transfers or income has Total $0 with no link, never "-$0". Tests in Tasks 5 and 6.
  5. "Clear all" with a section collapsed updates that section's header to "Any · N". Test in Task 4.
