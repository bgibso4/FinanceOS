Stacked Holdings and Activity

On the Investments page, Holdings and Activity sit side by side at the bottom of the account panel. Activity gets the narrow column, so it's small and hard to read. This stacks them: Holdings runs the full width, and Activity sits underneath with its own columns. Both sections can be collapsed from a larger header.

My calls

You approved the mock without picking on these two questions, so these are the defaults I offered.

  • M1Same number of activity rows
    It still shows 8 rows for All accounts and 5 for one account. Adding more rows or a "Show more" link can come later if you want it.
  • M2Closed sections stay closed
    If you close a section, it stays closed on your next visit, in this browser. The Targets cards already work this way.

Scope

Goals

  • Activity is readable at a glance
  • Holdings and Activity can each be collapsed
  • Section headers stand out more

Non-goals

  • Changing the chart, the holdings map or allocation
  • More activity rows, or filters on activity

Anti-goals

  • A second collapsible pattern next to the Targets one
  • Breaking the existing open-a-holding-by-account rows

1 · Layout and sections

  • The two-column grid at the bottom of AccountDetail becomes two stacked, full-width sections: Holdings first, then Activity.
  • Each section header is a button: an arrow, the title at 14px semibold primary, a count badge, and the existing hint on the right in uppercase. A border sits under the header. Clicking it opens or closes the section; both start open.
  • A closed header shows a one-line summary. Holdings: the total value and the top three tickers. Activity: the latest entry's date and title.
  • The open or closed state is saved in this browser (M2). The remembering code is taken out of CardShell into a shared useCollapsed hook that both use. Targets keeps its existing storage key, so cards you've already closed stay closed.

2 · Activity columns

  • Columns: Date · Activity (type, then ticker) · Account (All accounts only) · Shares · Price · Amount. A dash fills an empty Shares or Price.
  • The type is coloured: Buy blue, Sell accent, Dividend (including "Dividend reinvested") green, everything else secondary.
  • To make this possible, ActivityItem.title is replaced by kind (Buy, Sell, Dividend, Dividend reinvested, Interest, Fee and so on, or the institution's description for anything unrecognised) and symbol (the ticker, or the security name, or null). The naming rules stay the same.
  • On a phone-width screen, the table scrolls sideways inside its section rather than squeezing.
